What is actually happening

    
There is no CPU and no shell in this page. Every line after the boot sequence is written by
      the language model you picked, one chat completion per command. The machine's files, working
      directory, processes and clock are a small JSON object the model is handed back on the next
      turn — that object is the computer. Wipe it with Reset machine and the same command
      can produce a different, consistent machine.

    
Because the state is the only thing carrying over, you can break the computer on purpose:
      create a file, reboot it, read the file again; lock yourself out of a directory and ask the
      machine why. It is a world model for a machine that never existed.

    
The kernel picker marks each model: ✓ means it was measured against this
      app's system prompt and held the JSON contract, ⚠ means untested — it may
      answer in prose, and then the machine forgets its files between commands. Kernel
      openai/gpt-oss-20b is hidden entirely: it returned HTTP 400 on this prompt.

      storage. The price printed under the screen is computed from the usage the API reports and the
      per-token prices in /models.
